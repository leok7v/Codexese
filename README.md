# Codexese

Write anything. It becomes a page from a book nobody can read. Your
friend opens the picture in Codexese and the words come back, exactly as
you wrote them.

It is not encryption. Anybody who has Codexese can read a page. It is a
fun way to send messages, not a lock.

- iPhone and iPad: [Codexese on the App Store](https://apps.apple.com/app/id6837726784)
- Mac: the Mac App Store version is in review, or install with Homebrew:

      brew tap leok7v/tap
      brew trust leok7v/tap
      brew install --cask codexese

- Web page and privacy policy: [leok7v.github.io/Codexese](https://leok7v.github.io/Codexese/)

This repository holds only the Mac builds on its
[Releases](https://github.com/leok7v/Codexese/releases) page. Each is
signed with a Developer ID, notarized by Apple and stapled. The source
code is not public.
